# Підсумок — калькулятор угоди

Україномовний калькулятор вартості квартири, оформлення та супроводу угоди.

## Можливості

- Прямий розрахунок від ціни та зворотний — від бюджету покупця.
- Комісія агенції 5%, пенсійний збір 1% + 1% банку від суми збору, нотаріус 5 000 грн; ставки редагуються.
- Розподіл платежів між покупцем і продавцем, зокрема навпіл.
- Світла й темна теми, адаптивна верстка та делікатний патерн.
- «Детальніше»: зелена картка для скріншота з усіма платежами покупця.
- Формальні звіти через друк браузера → зберегти як PDF.

## Курс і GitHub Pages

GitHub Pages розміщує статичний сайт. Workflow `.github/workflows/pages.yml` щогодини (на 17-й хвилині), при змінах у `main` або вручну отримує готівковий курс ПриватБанку і публікує `rate.json`. Калькулятор використовує середнє між купівлею та продажем. Кнопка ↻ завантажує останній опублікований курс; вона не запускає новий запит до банку. Джерело та час отримання показані в інтерфейсі.

Розклад GitHub Actions може виконуватися із затримкою. Після 60 днів без активності в публічному репозиторії GitHub може вимкнути розклад; його можна ввімкнути у вкладці Actions. Курс старший за 2 години позначається як застарілий; ручне введення доступне завжди. Якщо банк тимчасово недоступний, зберігається попередній курс з його початковою датою.

Джерело: https://www.liqpay.ua/en/doc/api/public/exchange

## Локальний запуск

Потрібні Python 3 для перегляду та Node.js 24 для оновлення курсу й перевірок.

```sh
node scripts/update-rate.mjs
node test.cjs
python3 -m http.server 8000
```

Відкрити http://localhost:8000. Для публікації: Settings → Pages → Source → GitHub Actions.

## Файли

- `index.html`, `style.css` — інтерфейс.
- `calc.js` — розрахунки й округлення до центів.
- `app.js` — взаємодія, курс, деталізація й PDF.
- `scripts/update-rate.mjs` — отримання курсу без браузерних обмежень CORS.
- `test.cjs` — перевірки розрахунків, включно з 1 000 варіантів бюджету.

Адаптовано з власної версії сайту в Sites. Серверний маршрут замінено на оновлення статичного JSON через GitHub Actions; секрети й сторонні сервери для роботи не потрібні.
