# Підсумок — калькулятор угоди

Україномовний калькулятор вартості квартири, оформлення та супроводу угоди.

## Можливості

- Прямий розрахунок від ціни та зворотний — від бюджету покупця; ціна спочатку порожня.
- Комісія агенції 5%, пенсійний збір 1% + 1% банку від суми збору, нотаріус 5 000 грн; ставки редагуються.
- Пенсійний збір обчислюється від введеної оцінки, а за відсутності оцінки — від ціни квартири. ПДФО та військовий збір — від більшої з ціни й оцінки.
- Розподіл платежів між покупцем і продавцем, зокрема навпіл.
- Світла й темна теми, адаптивна палітра, патерни та рідкий фон із паралаксом.
- Один перемикний звіт для покупця чи продавця, формальний PDF через друк браузера.
- Мобільна кнопка «Швидко порахувати» переходить до покупцевого звіту з поточними налаштуваннями.
- «Поділитися з клієнтом» створює JPG картки з прямими зовнішніми краями, без кнопок. Підтримувані браузери відкривають системне поширення файлу; інші завантажують JPG.

## Курс і GitHub Pages

Workflow `.github/workflows/pages.yml` щогодини (на 17-й хвилині), при змінах у `main` або вручну отримує публічні дані графіка обмінника «Гарант» і публікує `rate.json`. Використовується останнє значення `best_bid` для USD/UAH, яке відображає графік при напрямку USD → UAH. Це не середнє між купівлею та продажем.

Джерело: https://garant.money/uk-UA/currency_rates/USD-UAH-kyiv
API графіка: POST https://garant.money/apiCl/cached/apiV2/get_best_rates_history

Кнопка ↻ завантажує останній опублікований курс; GitHub Pages не підтримує серверний проксі, а API Гаранта не дозволяє прямі запити з іншого домену. Розклад Actions може виконуватися із затримкою. Курс старший за 2 години позначається як застарілий; ручне введення доступне. При недоступності Гаранта зберігається попередній курс саме Гаранта та його початковий час; інші джерела не підставляються.

## JPG і конфіденційність

Експорт відбувається локально в браузері за допомогою html2canvas 1.4.1, збереженого в `assets/vendor` разом із MIT-ліцензією. Дані звіту не передаються сервісу рендерингу. Картинка готується після зміни даних чи оформлення; натискання використовує вже підготовлений File, щоб зберегти жест користувача для Web Share API на iOS. Остаточного одержувача вибирає користувач у системному меню.

## Локальний запуск

Потрібні Python 3 та Node.js 24.

```sh
node scripts/update-rate.mjs
node test.cjs
node scripts/rate.test.mjs
python3 -m http.server 8000
```

Відкрити http://localhost:8000. Для публікації: Settings → Pages → Source → GitHub Actions.

## Файли

- `index.html`, `style.css` — інтерфейс.
- `calc.js` — розрахунки й округлення до центів.
- `app.js` — взаємодія, курс, деталізація й PDF.
- `share.js` — локальна підготовка JPG і системне поширення.
- `scripts/update-rate.mjs` — отримання та перевірка курсу Гаранта.
- `test.cjs`, `scripts/rate.test.mjs` — перевірки розрахунків і джерела курсу.

### Валюта вводу та вигляд

Кнопка `$` біля основної суми перемикає USD / UAH з перерахунком за поточним курсом; працює для ціни та загального бюджету. При новому відкритті валюта завжди USD. Гривневий бюджет враховує округлення підсумку до копійок.

Початковий вигляд: класичний фісташковий фон без патерну та лісовий колір звіту. Власний вибір вигляду зберігається в `localStorage` цього браузера й має пріоритет над початковим; «Скинути» повертає початкову палітру. Кнопка поширення акцентна, PDF — світла. У PDF дата та назва формуються всередині документа й вирівняні за його краями.
